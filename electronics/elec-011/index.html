🔌 78xx / 79xx Voltage Regulators

Complete reference for fixed linear voltage regulators — output voltages, current ratings, packages, and wiring.

Typical wiring

Cin = 0.33µF (if regulator is far from filter cap)  |  Cout = 0.1µF minimum  |  79xx: same circuit, GND pin is common, polarity reversed

How to use

Current variants (suffix)

  • 78Lxx — 100 mA, TO-92 package
  • 78Mxx — 500 mA, D-PAK / TO-252
  • 78xx / L78xx — 1–1.5 A, TO-220
  • 78Hxx — 5 A, TO-3 (older designs)
  • Same applies to 79xx series (negative)

Minimum input voltage

  • Vin must exceed Vout by the dropout voltage
  • Typical dropout: 2–2.5 V at rated current
  • Example: 7805 needs Vin ≥ 7–8 V for stable 5 V out
  • For lower dropout, use an LDO regulator instead

Capacitor recommendations

Cin: 0.33 µF ceramic (near IN pin)
Cout: 0.1 µF ceramic (near OUT pin)
Optional: 10–100 µF electrolytic
for better transient response

Thermal considerations

  • Pdiss = (Vin − Vout) × Iout
  • TO-220: max ~1 W without heatsink
  • At higher power, heatsink + thermal paste required
  • Max junction temp: 125°C
  • Consider a buck converter for Vin/Vout ratio > 2×

78xx pin order (TO-220)

Pin 1 — INPUT
Pin 2 — GND
Pin 3 — OUTPUT

Flat face toward you,
pins pointing down: 1–2–3 left to right

79xx pin order (TO-220)

Pin 1 — GND
Pin 2 — INPUT
Pin 3 — OUTPUT

Different from 78xx!
Always verify with datasheet
