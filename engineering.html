⚙️ Engineering Tools

Browser-based calculators and reference tables for mechanical engineers

⚙️

ISO 286-1 Tolerance & Fits Calculator

🔧 Web Tool 🌐 Browser-based

Calculate limit deviations and fit types according to ISO 286-1. Enter nominal diameter, select hole and shaft tolerances — get ES, EI, es, ei values, fit type (clearance / transition / interference), and a visual tolerance zone diagram.
🔩

Bolt Tightening Torques (M3–M24)

🔧 Web Tool 🌐 Browser-based

Interactive tightening torque table for metric bolts M3–M24. Select strength class (4.6–12.9) and friction condition — get preload force (kN) and required torque (Nm) per ISO 898-1 / VDI 2230.
📐

ISO Metric Thread Standards (M1–M68)

📋 Reference Table 🌐 Browser-based

Complete ISO metric thread dimensions per DIN 13 / ISO 261. Coarse and fine pitches, pitch diameter (d₂), minor diameter (d₁), stress area (Aₛ), hex and Allen wrench sizes. Filterable and searchable.
