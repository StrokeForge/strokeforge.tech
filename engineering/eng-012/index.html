Formulas

Rectangle b × h

A = b · h
Ix = b · h³ / 12
Iy = h · b³ / 12
Wx = b · h² / 6
ix = h / √12

Circle d

A = π · d² / 4
Ix = π · d⁴ / 64
Wx = π · d³ / 32
ix = d / 4

Hollow rectangle B × H, wall t

b = B−2t, h = H−2t
A = B·H − b·h
Ix = (B·H³ − b·h³) / 12
Wx = Ix / (H/2)
ix = √(Ix / A)

Hollow circle D, wall t

d = D − 2t
A = π(D²−d²) / 4
Ix = π(D⁴−d⁴) / 64
Wx = π(D⁴−d⁴) / (32·D)
ix = √(D²+d²) / 4
