Formulas

UDL — uniform distributed load

R_A = R_B = q·L/2
M_max = q·L²/8  (at midspan)
f_max = 5·q·L⁴/(384·E·Ix)

Point load — midspan (a = L/2)

R_A = R_B = F/2
M_max = F·L/4
f_max = F·L³/(48·E·Ix)

Point load — general position a

R_A = F·(L−a)/L
R_B = F·a/L
M at a = R_A·a
f_max ≈ F·a·(L−a)·(2L−a)·√(3) / (27·E·Ix·L) if a≤L/2

Serviceability (L/δ)

  • Floors: L/300 – L/360
  • Roofs: L/200 – L/250
  • Purlins: L/200
  • Brittle finishes: L/360
