Formulas & notes

Section modulus Wx

Rectangle:    b·h² / 6
Circle:        π·d³ / 32
Hollow rect:  (B·H³−b·h³) / (6·H)
Hollow circ:  π·(D⁴−d⁴) / (32·D)

Bending stress

σ = M / Wx
η = σ / fy ≤ 1.0

For EC3 design: use MEd (factored) and fy/γM0 (γM0 = 1.0 for S235–S460). This tool uses characteristic fy directly — apply your own partial factors as needed.

Yield strengths (EN 10025)

  • S235: fy = 235 MPa (t ≤ 40 mm)
  • S275: fy = 275 MPa
  • S355: fy = 355 MPa
  • S420: fy = 420 MPa
  • S460: fy = 460 MPa
  • For t > 40 mm: fy is reduced per EN 10025 Table 7

Profile Wx source

IPE, HEA, HEB values are elastic section moduli Wy,el about the strong axis per EN 10034 / manufacturer tables. Plastic modulus Wpl is ~10–15% higher — not used here (elastic check only).
